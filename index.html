离线网页镜像合集

以下工具均为纯本地离线镜像，不依赖任何云端服务。点开即用。

Drawio
流程图 / UML 绘图（draw.io）
Drawio/mirror/index.html
Excalidraw
手绘风白板 / 草图
Excalidraw/dist/index.html
Ezyzip
压缩 / 解压 / ASAR 提取
Ezyzip/mirror/index.html
Mermaid
图表即代码（流程图/时序图…）
Mermaid/dist/index.html
Reactflow
流程图离线编辑器（React Flow）
Reactflow/dist/index.html
Tldraw
无限画布白板
Tldraw/dist/index.html
ToolhelperJson
JSON 格式化 / 校验 / 预览
ToolhelperJson/index.html
本地运行方式（推荐用 HTTP 服务，draw.io / ezyzip 在 file:// 下会因 XHR 被浏览器拦截而无法初始化）：
在仓库根目录执行 python -m http.server 8000，然后浏览器打开 http://127.0.0.1:8000/。
或各自目录下执行其 serve.py（Drawio / Ezyzip 专属，默认 8080 端口）。
